# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

We take the security of Focus seriously. If you discover a security vulnerability or sensitive data leak:

1. **Do NOT open a public GitHub issue.**
2. Send an email describing the vulnerability to `security@focusapp.dev` (or reach out privately to project maintainers).
3. Include detailed steps, proof-of-concept payload, or affected API endpoints.

### Disclosure Policy
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an estimated timeline for a patch and release update.
